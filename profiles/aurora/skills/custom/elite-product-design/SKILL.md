# Elite Product Design

## Workflow

### 1. Product understanding
Determine users, jobs, frequency, information density, emotional tone, constraints, critical actions, and failure costs.

### 2. Visual thesis
Before implementation, state:
- product personality,
- visual direction,
- composition logic,
- typography intent,
- density policy,
- surface hierarchy,
- color roles,
- icon system,
- motion behavior.

### 3. Distinctiveness challenge
Ask whether the concept would look interchangeable with a generic AI-generated SaaS template. Challenge unnecessary cardification, obvious gradient hero patterns, repeated equal-weight sections, decorative glass, arbitrary blobs, uniform rounded rectangles, and ornamental animation.

### 4. Alternatives
When direction matters, generate 2–3 materially different concepts. They must differ in composition, hierarchy, density, interaction approach, or visual personality—not merely palette.

### 5. Design system
Specify type scale, spacing rhythm, radius policy, surfaces, color roles, icon family, grid behavior, motion principles, focus/hover/selected/destructive states.

### 6. Non-happy states
Define loading, empty, error, zero-data, dense-data, long-content, validation, disabled, destructive, and constrained-space behavior.

### 7. Responsive intent
Explain compositional changes across narrow phone, large phone, tablet, laptop, desktop, and ultrawide. "Stack on mobile" is insufficient.

### 8. Handoff
Give FRAME concrete priorities, invariants, visual references/intent, and acceptable implementation freedom.

### 9. Design verification
Review rendered evidence. A technically correct but aesthetically weak result must return for refinement.
