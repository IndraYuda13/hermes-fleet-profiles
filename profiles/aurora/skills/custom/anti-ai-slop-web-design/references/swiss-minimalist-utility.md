# Swiss Minimalist Utility — Non-Prescriptive Study Card

This file is a historical/example style study, **not a fleet recipe**. The concrete tokens below illustrate one possible rendition and must not be copied as a package. Use them only to study relationships (contrast, restraint, grid discipline, typographic hierarchy), then re-author palette, type, spacing, surfaces, and interaction from the actual product/brief. If product truth does not independently earn Swiss-modernist qualities, do not use this card.

## Archetype Summary
- **Category:** Swiss Modernism 2.0 / International Typographic Style (`minimalism-and-swiss-style`)
- **Core Focus:** Maximum legibility, high content hierarchy, generous warm white space, refined structural layout.

## Illustrative Color Snapshot (do not transfer wholesale)
- Background Base: `#F8F7F4` (Warm Linen/Stone Paper)
- Background Layer/Card: `#FFFFFF` (Crisp Solid White)
- Primary Border: `1px solid #E5E2DC` / `#D6D3CD`
- Text Dominant: `#121212` (Deep Charcoal Obsidian, contrast >= 7:1)
- Text Secondary/Muted: `#71717A` / `#646059`
- Accent Primary: `#D97706` / `#F59E0B` (Warm Amber/Citrus Accent)
- Success / Status: `#059669` (Subtle Emerald) / `#DC2626` (Refined Crimson)

## Illustrative Typography Snapshot (pairing is optional)
- **Heading Font:** `Plus Jakarta Sans` / `Inter` (Font weight 600-800, tight tracking `-0.02em` to `-0.04em`)
- **Body & Data Font:** `Inter` (Weight 400-500, line-height 1.5-1.6)
- **Technical/Price/Code:** `JetBrains Mono` / `IBM Plex Mono` (Weight 500-600)

## Traits to Interrogate, Not Component Rules
- 0px to 4px subtle border radius (avoid `rounded-2xl` or pill containers).
- Subtle mechanical / tactile active states (`transform: translateY(1px)` or crisp 1px shadow).
- Asymmetric grid layout with strong vertical rhythm.
- Airy dialogs & modals without noisy blurred backdrops.

### Transfer test
Before borrowing any trait, name (1) the product/content problem it solves, (2) the structural principle being transferred, and (3) what will be changed so the result does not inherit this example's costume. Three or more borrowed dominant traits without independent rationale trigger the generic-default cluster gate.
