# Anime Streaming Design System (Obsidian Cinema)

## Principles
1. Deep Obsidian Base (`#08080A`) with 1px specular white borders (`rgba(255,255,255,0.12)`).
2. Floating Frosted Command Capsule with integrated Cmd+K search.
3. Custom HTML5 video overlay with 4px to 8px scrubber timeline and tabular numbers.
4. Dual-mode theater layout (Split screen 72/28 vs Full-width theater).
5. Dynamic ambient backdrop glow keyed to active anime poster artwork.
