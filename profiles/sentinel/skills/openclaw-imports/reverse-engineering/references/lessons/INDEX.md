# Reverse Engineering Lessons Index

Use this folder as the durable learning area for reverse-engineering progress, milestones, and reusable experience.

## Rules

- Add a new case note under `cases/` when a target deserves continuity across sessions.
- Add a new pattern note under `patterns/` when a technique or lesson is reusable across multiple targets.
- Keep entries distilled and reusable.
- Do not store raw secrets, credentials, private dumps, or proprietary payloads here.
- When a case reaches a meaningful milestone, append the reusable takeaway here as a pointer.

## Suggested entry format

- `YYYY-MM-DD | target/topic | key lesson | file`
