# Investigation Ledger

Use this as the default per-target progress ledger. Copy the template into a case note under `references/lessons/cases/` when a new engagement starts, or adapt it into a workspace-local note if the case is large.

```markdown

- Name:
- Type:

## Milestones
- [ ] target and goal defined
- [ ] interface map complete
- [ ] artifact inventory complete

```

## Usage rules

- Keep the ledger short, factual, and incremental.
- Promote confidence only when evidence quality improves.
- Record failed probes too, especially when they save future time.
- Capture one distilled lesson before closing or pausing the case.
