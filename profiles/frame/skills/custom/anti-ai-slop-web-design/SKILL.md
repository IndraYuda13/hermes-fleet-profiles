# Anti-AI Slop Web Design & Aesthetic Enforcement

This skill provides an authoritative, fleet-wide design governance standard to eliminate generic "AI slop" and elevate all web user interfaces, dashboards, 3D experiences, and landing pages to museum-grade, editorial, and architectural excellence.

**Fleet Invariant**: All fleet members involved in frontend design, implementation, and review (AURORA, FRAME, LENS, PRISM, and ORION) MUST read and apply the principles in this skill before authoring or modifying any UI. This skill is immutable and must not be altered unless explicitly requested by the user.

## The 7 Universal Anti-AI Slop Laws

For deep technical breakdowns, mathematical formulas, and code references, call:
`skill_view("anti-ai-slop-web-design", "references/anti-ai-slop-universal-principles.md")`

1. **Color Palette — End SaaS Cyan/Purple Fatigue**:
   - BANNED: Pitch-black `#000000` combined with electric purple (`#8b5cf6`), neon cyan (`#06b6d4`), and multi-color gradient blur blobs.
   - MANDATORY: Warm, architectural dark foundations (e.g. Deep Roasted Espresso `#131211`, Slate Graphite `#18181b`).
   - Cohesive 3–5 tone botanical/mineral families (Warm Sand `#a88f6c`, Deep Moss `#3d633a`, Soft Sage `#6b9666`, Warm Amber `#db8f38`, Soft Champagne `#ebdcb8`). Non-blown additive highlights.
2. **Typography as Primary Architecture**:
   - BANNED: Single default sans-serif (Inter/Roboto) for all copy; meaningless gradient text fills.
   - MANDATORY: The Typographic Triad (Editorial High-Contrast Serif for display, Modern Geometric Sans for narrative, Technical Monospace for telemetry).
   - Extreme optical scale contrast (`clamp(3.5rem, 6vw, 6.5rem)` titles with tight tracking vs micro-uppercase labels with `+0.22em` letter-spacing). Copy is sacred: visuals must repel away from text (GPU halo + HTML scrim).
3. **Demolition of the Card Grid Addiction**:
   - BANNED: Repetitive 3-box or 4-box card grids with identical borders and generic icons.
   - MANDATORY: Asymmetrical spatial zoning, alternating section focus, and generous negative space (`clamp(7rem, 11vw, 13rem)` clearance).
4. **Tactile Micro-Physics vs Cheap Macro Gimmicks**:
   - BANNED: Whole-card hover tilting, aggressive mouse-follow wobble, and floating decorative spheres.
   - MANDATORY: Macro compositions remain calm and anchored; motion is concentrated in subtle tactile micro-interactions (localized surface displacement $R < 0.65$, smooth kinetic scrolling via Lenis synchronized to RAF).
5. **Shape Fidelity & Authentic Silhouettes (Anti-Blob Gate)**:
   - BANNED: Noisy spheres, vague organic blobs, and unidentifiable particle clouds labeled as "AI core".
   - MANDATORY: Black-and-white silhouette test must pass. Anatomical and mechanical realism (bilateral fissure on brain, helical ridges on bulb, recognizable continents on globe).
6. **Space-Conscious Mobile Re-Composition**:
   - BANNED: Compressing desktop layout into 100% width, causing copy cards to smother 3D/visual art.
   - MANDATORY: Two-tier vertical stage (top 50% visual hero window, bottom 50% copy dock). Desktop margin rails metamorphose into bottom thumb floating pills.
7. **Creator != Certifier (Adversarial Quality Governance)**:
   - BANNED: Implementer self-certifying that "the UI looks great".
   - MANDATORY: Independent review (LENS/PRISM) via real headless CDP rendering. Zero-bypass remediation routing for any visual flaw.

## Verification

To verify that an interface adheres to this skill:
1. Palette Check: Confirm background is NOT pure `#000000` and contains zero `#06b6d4` / `#8b5cf6` clichés.
2. Silhouette Check: Render the scene in binary silhouette; verify shapes are unmistakable.
3. Contrast Check: Measure copy contrast against moving background; verify $\ge 7.0:1$ (WCAG AAA).
4. Viewport Check: Verify zero horizontal overflow on 360px, 390px, 768px, 1440px, 1920px.
