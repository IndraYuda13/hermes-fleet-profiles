# Platform Matrix for Technical Certifications & Badges

Detailed reference of verified, high-yield platforms providing free or low-cost technical certificates and digital badges.

| Platform | Core Domains | Credential Format | Credly Badge | Speedrun Feasibility | Direct Portal URL |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Microsoft Learn Applied Skills** | Azure Cloud, AI, Security, DevOps | Official Certificate & Badge | Yes (MS Learn / Credly) | **Very High** (Direct 1.5-2h scenario lab assessment, no video gate) | `https://learn.microsoft.com/credentials/applied-skills/` |
| **AWS Educate** | Cloud, Serverless, Storage, Compute, GenAI | Digital Training Badge | Yes (Credly) | **High** (Jump to Knowledge Checks & final assessment) | `https://aws.amazon.com/education/awseducate/` |
| **Cisco Networking Academy (Skills for All)** | Cybersecurity, Networking, Python, Linux | Digital Badge & Certificate | Yes (Credly) | **High** (Self-paced, unblocked quizzes & final exam) | `https://skillsforall.com/` |
| **HackerRank Skills** | Problem Solving, Python, JS, React, Node, SQL | Verified Skill Certificate | No (Direct HackerRank URL) | **Instant** (Direct 30-90m live coding assessment, 0 tutorials) | `https://www.hackerrank.com/skills-verification` |
| **freeCodeCamp** | Web Dev, JS Algorithms, Backend, InfoSec, ML | Verified Certificate (300 Hours JP) | No (Direct FCC URL) | **High** (Direct submission of 5 required project repositories) | `https://www.freecodecamp.org/` |
| **IBM Cognitive Class** | Data Science, Python, K8s, Kafka, AI | IBM Digital Badge | Yes (Credly) | **High** (Skip video, take chapter review & final exam directly) | `https://cognitiveclass.ai/` |
| **Fortinet Training Institute** | Cybersecurity Fundamentals, Network Security | FCF / FCA Badge | Yes (Credly) | **Medium-High** (Short reading modules, multiple-choice quiz) | `https://training.fortinet.com/` |
| **Kaggle Learn** | Python, Pandas, Intro to ML, Data Viz | Course Certificate | No (Kaggle URL) | **High** (Execute interactive notebook code cells in 15-30m) | `https://www.kaggle.com/learn` |

## Deprecated / Sunset Warnings
- **Postman Student Expert:** Sunset / deprecated. Do not direct users to this obsolete badge pathway.
- **Oracle University Free Campaigns:** Time-gated. Available only during annual promotional windows (typically Q3-Q4). Verify active promotion before attempting.
